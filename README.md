# Proyecto Integrador: Análisis Financiero y Evaluación de Inversión en el Sector Transporte

## 📌 Descripción del Proyecto
Evaluación económica, financiera y de ingeniería económica para la renovación de flota vehicular en una empresa de transporte de carga en Ecuador. El proyecto analiza la sustitución de un activo fijo mediante crédito bancario Pyme y evalúa su viabilidad mediante flujos de caja libre ($FCFF$), $VAN$, $TIR$ y análisis de sensibilidad.

## 🛠️ Estructura del Repositorio
* `agents/`: Definición y prompts de los agentes IA especializados.
* `data/`: Bases de datos crudas y procesadas del sector transporte (BCE, SRI, Cías).
* `src/`: Código fuente de análisis financiero y Dashboard en Next.js.
* `evidence/`: Registros de interacción y validación con IA agéntica.

## 🚀 Despliegue
Dashboard interactivo desplegado en Vercel.
