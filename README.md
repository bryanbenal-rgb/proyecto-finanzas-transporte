# Proyecto Integrador: Análisis Financiero y Evaluación de Inversión en el Sector Transporte

## 🚀 Despliegue
🌐 **Dashboard en vivo:** https://proyecto-finanzas-transporte-ten.vercel.app

## 📌 Descripción del Proyecto
Evaluación económica, financiera y de ingeniería económica para la renovación de flota vehicular en una empresa de transporte de carga en Ecuador.  
El proyecto analiza la sustitución de un activo fijo mediante crédito bancario Pyme y evalúa su viabilidad mediante flujos de caja libre ($FCFF$), $VAN$, $TIR$ y análisis de sensibilidad.

## 🛠️ Estructura del Repositorio
* `agents/`: Definición y roles de los agentes IA.
* `data/`: Bases de datos crudas y procesadas del sector transporte.
* `src/`: Código fuente de análisis financiero y dashboard.
* `evidence/`: Evidencias del uso de IA.
* `docs/`: Informe final y documentación adicional.
