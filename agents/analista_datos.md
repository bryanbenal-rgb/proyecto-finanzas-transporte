# Agente de Datos

## Responsabilidad
Recolectar, limpiar, documentar y validar las bases de datos de costos operativos y estados financieros del sector.

## Entradas
- Hojas de costos de transporte, mantenimiento, neumáticos y saldos operativos.

## Productos Esperados
- Base de datos procesada en `data/processed/`.
- `diccionario_datos.md` documentado con variables y unidades.
